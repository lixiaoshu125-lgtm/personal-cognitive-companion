# 深度对话 (Personal Cognitive Companion)

一个以对话为中心的 Obsidian 插件：和你的笔记对话，澄清观点，追踪认知变化，把 AI 辅助思考的结论沉淀到知识库里。

> 目标不是记更多笔记，而是让已有材料持续参与思考。

## 已实现

- **认知伴侣首页**：自由提问、讨论当前笔记、本周回顾、恢复历史对话
- **AI 对话引擎**：基于笔记上下文的多轮对话，支持暂停/恢复，自动归档
- **本周主题准备**：扫描全 Vault 笔记 + 拉取新闻热点，AI 生成可讨论的候选主题
- **笔记索引系统**：为所有笔记建立标题+标签索引，对话中按关键词检索上下文
- **Wiki 自动生成**：对话结论经用户确认后，AI 自动生成结构化 Wiki 页面
- **结论确认机制**：AI 结论须经确认/修改/否定后才写入；区分用户确认、AI 推断、待验证、已拒绝、已取代
- **对话错误恢复**：自动检测损坏的对话状态并修复；AI 错误信息自动脱敏（隐藏 API key 和路径）
- **连接测试**：设置页内置 API 连通性检测
- **源笔记安全**：只读源笔记，写入限制在配置的系统目录内

## 安装

### 手动安装

1. 下载 `main.js`、`manifest.json`、`styles.css`
2. 放入 `<你的Vault>/.obsidian/plugins/personal-cognitive-companion/`
3. 重启 Obsidian，在"设置 → 第三方插件"中启用 **深度对话**

### 配置

在插件设置中填写：
- DeepSeek API Key
- API Endpoint（默认 `https://api.deepseek.com/v1`）
- 模型名称（默认 `deepseek-chat`）

## 使用

点击左侧栏 ✨ 图标打开首页。四个入口：

1. **自由提问**：输入问题，AI 结合你的笔记上下文回答
2. **讨论当前笔记**：以当前打开的 Markdown 笔记为起点
3. **开始/继续本周回顾**：准备本周主题或恢复进行中的讨论
4. **继续历史对话**：从已保存的对话中恢复

命令面板两个入口：
- 打开深度对话
- 认知对话：从当前笔记

## 笔记预处理思路

本插件适合**已整理好的笔记库**。如果你和我一样，手机里攒了七八年的碎片备忘录，直接导入是没用的。可以先用脚本做预处理：

1. **机械过滤**：正则清除纯链接、提取码、10 字以下碎片
2. **AI 批量分类**：用 DeepSeek 逐批归类（自我分析 / 做事方法 / 客观记录等 7 类）
3. **质量评分分流**：AI 评 1-5 分，4+ 分导入知识库，1-2 分排除，3 分人工审核

核心思路：**规则优先于 AI**（能正则排除的先排除，省 API 调用），**断点续传**（几千条不可能一次跑完），**AI 结果当辅助**（不必追求完美分类，重点是把明显垃圾排除）。

这个预处理流程独立于本插件，不包含在本仓库中。详细实现思路见上文，可根据自己的笔记结构调整。

## 当前限制

- 大型 Vault（5000+ 笔记）的主题准备可能需要较长时间
- 尚未接入 Smart Connections 等外部索引插件
- 目前只在 Windows 桌面端 Obsidian 上完整验证过
- Wiki 文件扫描在某些平台可能遗漏 Obsidian 外部创建的文件（已有 fallback 机制）

详细路线图见 [ROADMAP.md](ROADMAP.md)。

## 数据与隐私

### 发送给 AI 的内容

- 当前对话消息
- 你主动选择讨论的笔记内容或相关上下文
- 本周主题准备所需的相关笔记摘要（标题 + 路径 + 开头约 300 字符）

### 本地存储

- 插件设置和对话保存在 Obsidian 的 `data.json` 中
- Wiki 和认知模型文件写入配置的系统目录（默认 `_个人认知系统/`）
- 源笔记不会被修改

API Key 以明文保存在本机 `data.json` 中。**不要提交或分享这个文件。**

## 开发

需要 Node.js 22+。

```bash
npm install
npm test
npm run typecheck
npm run build   # 在仓库根目录生成 main.js
```

目录结构：

```
src/       插件源码
tests/     单元测试 + E2E 测试
```
